Pollymetric now shows what your AI agents are doing to your Mac, and what they leave behind.

### What's new

- **Local Servers:** every server running on your Mac, which agent or app started it, how long it's been up, and whether other machines on your network can reach it. Servers still running after the agent that started them has quit are flagged as **left running**.
- **Worktrees:** the extra copies of your projects that agents make for each task, how much space each holds, when it was last touched and which agent made it, with safe removal. Your branches stay, and anything unsaved gets a clear warning first.
- **Plugins & Skills:** what each agent has been given, what each plugin runs, and anything worth a second look, like tools that run whatever a registry serves that day or keys stored in plain text.
- **Local models by name:** a model holding gigabytes of memory shows up as the model it has loaded (for example "Ollama · llama3.1:8b"), not "ollama".
- **Needs attention now leads with agent leftovers:** a server left running, a key stored in plain text, or worktrees nobody's used in a week.

### Also in this release

- Helpers Pollymetric starts for you no longer inherit its Full Disk Access.
- Agent conversations always run read-only until you approve each step, with no standing "always allow".
- Tighter handling of anything secret-looking in command lines.
- Under 1% CPU while it watches.

### Install

Download **Pollymetric.dmg** below, open it, and drag Pollymetric into Applications.

> **Early build:** this version isn't notarized by Apple yet, so the first time you open it macOS will say it can't verify the developer. Open **System Settings → Privacy & Security** and click **Open Anyway**.

Requires macOS 14 Sonoma or later, on Apple silicon or Intel.
